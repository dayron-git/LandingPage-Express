# Landing Page solo con Express

Landing page con enrutamiento .js, proyecto forkeado del profesor

## Instrucciones 
- Verificar que tenés Node.js instalado: `node -v`
- nstalar las dependencias de forma segura (usando --ignore-scripts para evitar la ejecución automática de scripts de instalación, como medida de seguridad frente a paquetes npm comprometidos): `npm ci --ignore-scripts`
-Revisar vulnerabilidades conocidas en las dependencias: `npm audit`

- Corregir automáticamente lo que se pueda sin romper compatibilidad: `npm audit fix`

- Levantar el servidor de desarrollo: `npm run dev`
